# Kleinere Abteilungen im Admin-Dashboard

Dieses Update macht das Admin-Dashboard kompakter:

- kleinere Abteilungs-Kacheln
- kleinere Abteilungs-Überschriften
- weniger Abstand zwischen Bereichen
- kleinere Auftragskarten
- bis zu 3 Auftragskarten nebeneinander auf großen Bildschirmen
- mehr Inhalt sichtbar ohne Scrollen

Ersetzen:

- `public/style.css`

Nicht ersetzen:

- `server.js`
- `.env`
- `views/admin.ejs`
