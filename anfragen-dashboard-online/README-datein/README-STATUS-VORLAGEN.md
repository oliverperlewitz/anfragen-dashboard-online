# Status-Vorlagen für jeden Status

Dieses Update ergänzt für jeden Wert im Dropdown „Neuer Status“ mindestens eine Vorlage.

## Ersetzen

- `views/admin.ejs`

## Nicht ersetzen

- `server.js`
- `.env`
- `data`
- `node_modules`
- `public/style.css`
- `public/invoice-lite.js`

## Enthaltene Status

- Neu
- Gesehen
- Rückfrage offen
- Besichtigung geplant
- Angebot wird erstellt
- Angebot gesendet
- Warten auf Kundenantwort
- Angenommen
- Termin vereinbart
- In Bearbeitung
- Pausiert
- Erledigt
- Abgerechnet
- Bezahlt
- Abgelehnt
- Storniert
