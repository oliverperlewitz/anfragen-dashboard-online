# Statusbereich wirklich untereinander

Dieses Script schreibt den Fix direkt in `views/admin.ejs`.
Dadurch ist es stärker als die bisherigen CSS-Dateien.

## Datei hinzufügen

- scripts/statusbereich-wirklich-untereinander.js

## Ausführen

node scripts/statusbereich-wirklich-untereinander.js

## Danach pushen

git add .
git commit -m "Statusbereich wirklich untereinander angeordnet"
git push

## Ergebnis

1. Status ändern & Kundeninfo schreiben
2. Gesendete Status-Infos anzeigen
3. Nachweis & Archiv
4. Löschen

Alle Boxen werden gleich breit. Löschen wird rot dargestellt.
