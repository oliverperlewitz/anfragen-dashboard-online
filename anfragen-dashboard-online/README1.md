# GrünWerk Gartenbau Dashboard

Diese Version nutzt dein neues Gartenbau-Layout und ein erweitertes Anfrageformular.

## Lokal starten

```bash
npm install
copy .env.example .env
npm start
```

Website: http://localhost:3000
Admin: http://localhost:3000/admin

## Online bei Render

Build Command:

```bash
npm install
```

Start Command:

```bash
npm start
```

Environment Variables:

```env
ADMIN_USERNAME=admin
ADMIN_PASSWORD=dein-sicheres-passwort
SESSION_SECRET=ein-langer-geheimer-text
NODE_VERSION=22
```
